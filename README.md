# Student Marks Calculator

A simple web application developed using **Java Servlet and JSP** to calculate a student's total marks, average, and final grade for three subjects.

## Features
- Enter student name and marks for three subjects.
- Validate marks between 0 and 100.
- Calculate total marks and average.
- Display the final grade on a separate result page.
- Return to the input form.

## Technologies Used
- Java
- Jakarta Servlet
- JSP
- Maven
- Apache Tomcat 10.1

## Sample Output
- **Student Name:** SELVAKUMAR S
- **Total Marks:** 240 / 300
- **Average Marks:** 80.00
- **Final Grade:** B

## How to Run
1. Import the Maven project into Eclipse.
2. Configure Apache Tomcat 10.1.
3. Run the project on the server.
4. Open `http://localhost:8080/student-marks-app/` in your browser.
